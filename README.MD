# Обраний домен

## Сервіс для резервування столиків у ресторані

Система призначена для онлайн-резервування столиків у ресторані. Користувач може переглядати доступні столики, обирати дату, час та кількість гостей і створювати резервування.

Кожен столик має власний номер, кількість місць та тип розташування: звичайний столик, столик біля вікна або столик на терасі.

Користувач може мати декілька резервувань на різні дати та час. Кожне резервування пов'язане з конкретним користувачем і конкретним столиком та містить дату, час і кількість гостей.

Система не дозволяє створити резервування столика, якщо він уже заброньований на вибрані дату та час.

Користувач може скасувати власне резервування. У такому випадку запис про резервування видаляється з системи, після чого столик знову стає доступним для резервування на відповідний час.

Користувач також може залишити оцінку та текстовий відгук про ресторан.
