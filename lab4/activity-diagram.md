title UC-06 «Забронювати столик» - Activity-діаграма

|Користувач|
|ReservationController|
|AuthController|
|Table|
|Reservation|
|Email Service|
|EmailConfirmation|

|Користувач|
start

:Ввести параметри пошуку:
дата, час, кількість гостей, тип столика;

|ReservationController|
:Перевірити коректність параметрів;

if (Параметри коректні?) then (ні)
|Користувач|
:Отримати повідомлення про помилку;
note right: Користувач повторює введення\nпараметрів пошуку
detach
endif

|Table|
:Підібрати столики вибраного типу,
місткість яких відповідає кількості гостей;

|Reservation|
:Перевірити доступність підібраних столиків
на вибрані дату й час;

|ReservationController|
if (Є доступні столики?) then (ні)
|Користувач|
:Отримати порожній результат
та пропозицію змінити параметри;
note right: Користувач повторює пошук\nз іншими параметрами
detach
endif

|Користувач|
:Отримати список доступних столиків;
:Обрати столик та перейти до оформлення бронювання;

|ReservationController|
:Перевірити, чи авторизований користувач;

while (Користувач не авторизований?) is (так)
|Користувач|
:Отримати сторінку реєстрації або входу;

    if (Погоджується зареєструватися або увійти?) then (ні)
        :Відмовитися від реєстрації або входу;
        note right: Бронювання не створюється
        stop
    endif

    :Надіслати запит на реєстрацію або авторизацію;

    |AuthController|
    :Обробити запит та повернути результат
    (успішно / помилка);

    |Користувач|
    :Отримати результат реєстрації або авторизації;

    while (Реєстрація або авторизація неуспішна?) is (так)
        if (Користувач повторює спробу?) then (так)
            |Користувач|
            :Повторно надіслати запит;

            |AuthController|
            :Повторно обробити запит та повернути результат;

            |Користувач|
            :Отримати результат реєстрації або авторизації;
        else (ні)
            :Завершити процес;
            note right: Бронювання не створюється
            stop
        endif
    endwhile (ні)

    |ReservationController|

endwhile (ні)

|Користувач|
:Ввести контактні дані: ім'я та прізвище,
номер телефону, електронну адресу;
:Підтвердити бронювання;

|ReservationController|
:Повторно перевірити доступність обраного столика;

|Reservation|
:Перевірити наявність бронювань
на обраний столик, дату й час;

|ReservationController|
if (Столик усе ще доступний?) then (ні)
|Користувач|
:Отримати повідомлення, що столик став недоступним;
note right: Бронювання не створюється.\nКористувач може повернутися до пошуку
stop
endif

|Reservation|
:Створити та зберегти бронювання
разом із контактними даними;

fork
|ReservationController|
:Передати Email Service дані бронювання
та електронну адресу з оформлення;

    |Email Service|
    :Спробувати надіслати лист-підтвердження;

    |ReservationController|
    :Отримати результат надсилання листа;

    |EmailConfirmation|
    :Зберегти результат надсилання листа;

fork again
|ReservationController|
:Підготувати інформацію про створене бронювання;
end fork

|ReservationController|
:Сформувати повідомлення про результат
бронювання та надсилання листа;

|Користувач|
:Отримати результат: бронювання створено,
лист-підтвердження надіслано або не надіслано;

note right: Якщо лист не надіслано,\nбронювання залишається чинним

stop
@enduml
